# Agent Instructions

This file is the entry point for all agent sessions.

All project rules, architecture decisions, module status, and coding conventions
are maintained in `.agents/`.
Before editing or committing, read `.agents/rules/AGENT_ROUTER.md` and
`.agents/rules/GLOBAL_RULES.md`.

There is no DESIGN.md at this level. The design system lives in `frontend/DESIGN.md` and
governs frontend work only; read it before writing any frontend code.
